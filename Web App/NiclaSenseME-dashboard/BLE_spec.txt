BLE Sense - BLE specifications.txt
==================================

GAP (Adversisement)
-------------------
Local name:    BLESense-<last 4 characters of BT address>
Serivice UUID: 19b10000-0000-537e-4f6c-d104768a1214


GATT
----

Service
~~~~~~~

UUID: 19b10000-0000-537e-4f6c-d104768a1214


Version Characteristic
~~~~~~~~~~~~~~~~~~~~~~

UUID:       19b10000-1001-537e-4f6c-d104768a1214
Properties: read
Value size: 4 bytes
Data format: 32-bit unsigned integer (little endian)
Description: Version of firmware

Temperature Characteristic
~~~~~~~~~~~~~~~~~~~~~~~~~~~~

UUID:       19b10000-2001-537e-4f6c-d104768a1214
Properties: read
Value size: 4 bytes
Data format: 32-bit float (little endian)
Description: Temperature sensor value Celcius

Acceleration Characteristic
~~~~~~~~~~~~~~~~~~~~~~~~~~~

UUID:       19b10000-5001-537e-4f6c-d104768a1214
Properties: notify
Value size: 12 bytes
Data format: Array of 3 x 32-bit floats (little endian)
Description: X, Y, Z acceleration values in G's (IMU data)

Gyroscope Characteristic
~~~~~~~~~~~~~~~~~~~~~~~~

UUID:       19b10000-6001-537e-4f6c-d104768a1214
Properties: notify
Value size: 12 bytes
Data format: Array of 3 x 32-bit floats (little endian)
Description: X, Y, Z gyroscope values in degrees per second

Analog A1 Characteristic
~~~~~~~~~~~~~~~~~~~~~~~~

UUID:       19b10000-a001-537e-4f6c-d104768a1214
Properties: read
Value size: 4 bytes
Data format: 32-bit unsigned integer (little endian)
Description: Raw analogRead(A1) value

---
NOTE: The humidity, pressure, quaternion, RGB LED, BSEC, CO2 and gas
characteristics from the original demo sketch were removed to keep the
logged dataset limited to temperature, IMU (accelerometer), gyroscope,
and pin A1 - the fields persisted to MongoDB by the dashboard.
